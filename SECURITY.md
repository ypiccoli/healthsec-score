# Segurança

## Reportar uma vulnerabilidade

Encontrou um problema de segurança no HealthSec Score? **Não abra uma issue pública.** Use o relato privado do GitHub: aba **Security** → **Report a vulnerability**.

Descreva o problema, como reproduzir e o impacto esperado. Respondemos assim que possível. Este é um projeto acadêmico mantido por estudantes, sem SLA.

## O que o projeto não coleta

O HealthSec Score é um site estático. Ele não tem servidor, banco de dados nem login, e não envia as respostas do questionário para lugar nenhum. As respostas ficam no navegador de quem responde (`localStorage`) e, se a pessoa quiser, num arquivo `.json` que ela mesma baixa.
